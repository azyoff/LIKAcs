# Update flow: GitHub Release → laptop → every cafe PC

Website: <http://likaapps.com>

```
[Tag vX.Y.Z] -> release.yml (windows-latest)
   PyInstaller -> LIKAcs.exe, LIKAcs-ControlCenter.exe, LIKAcs-StationAgent.exe
   SHA256SUMS.txt  (and README.md / LICENSE attached)
                     |
                     v
[Control Center / Updates tab]
   GET https://api.github.com/repos/azyoff/LIKAcs/releases/latest
   compare tag with VERSION  ->  Download & Verify .exe
   sha256 checked against asset digest or SHA256SUMS.txt
                     |
                     v
[Push Update to ALL Station PCs]  (signed, chunked, one click)
   POST /update-begin   {version, size, sha256, filename}
   POST /update-chunk   {id, offset, data(base64)}  x N   (512 KiB chunks)
   POST /update-finish  {id, restart}
                     |
                     v
[Each Station Agent]
   verifies size + SHA-256 again, discards on mismatch
   stages %APPDATA%\LIKAcs\updates\LIKAcs-vX-....exe.new
   pending-update.json saved, heartbeat advertises staged version
   optional: writes a .cmd swap helper and exits silently
                     |
                     v
[.cmd helper, Windows only]
   wait until the running agent PID has exited (tasklist)
   move /Y staged -> original exe
   start "" original --mode=station --silent
```

## Why a swap helper

Windows locks a running `.exe`; it cannot be overwritten in place. The helper
is a plain batch script generated by `update.build_swap_script()` — no
installer, no service, no elevation. It waits for the process to exit, replaces
the binary and restarts the agent in silent tray mode. Games are **not**
terminated by an update, so a live match is never interrupted.

## Safety

* The laptop verifies the GitHub asset hash **before** pushing.
* Every station independently re-verifies hash and size **before** staging.
* All LAN traffic is HMAC-signed and replay-protected (see [PORTS.md](PORTS.md)).
* A failed transfer is deleted and reported; nothing is executed automatically
  until the operator opts into the restart.
* `SHA256SUMS.txt` is attached first in the release file list so the updater
  can always find it.

## Manual / offline updates

Copy the verified `LIKAcs.exe` to each PC (USB stick) and rename/replace it
while the agent is closed; the next start picks up the new version. The
Control Center shows the installed version in the About dialog, status bar
and header.
